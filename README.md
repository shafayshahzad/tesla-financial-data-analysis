# Tesla Inc. — Financial & Operational Data Analysis (2016–2023)

## Overview
A comprehensive data analysis of Tesla's financial performance, sales trends, 
production costs, employee data, and service revenues across all 4 models 
(Model S, Model X, Model 3, Model Y) from 2016 to 2023.

---

## Objectives
- Analyze Tesla's quarterly sales performance across all models (2016–2023)
- Examine production cost trends and salary data by role
- Calculate service revenue across aftermarket parts, software upgrades, insurance & roadside assistance
- Apply advanced Excel functions for data extraction, aggregation & statistical analysis
- Build a relational database from the Tesla dataset

---

## Dataset
| Table | Description |
|-------|-------------|
| Sales Data | Quarterly sales by model (2016–2023) |
| Production Costs | Cost per model per year |
| Salary Data | Salary ranges by role (2016–2023) |
| Services Revenue | Revenue by service type & model |
| Employee Count | Total employees per year |

## Key Findings
- Tesla shifted from premium (Model S/X) to mass-market dominance (Model 3/Y)
- Model Y achieved **302,000 units** in Q3 2023 — highest single-quarter sales
- Model 3 cumulative sales: **2,165,187 units** (2017–2023)
- Service revenue grew from **$1.13B (2016)** to **$5.62B (2023)** — a **397% increase**
- Software & upgrades became the fastest-growing service segment
